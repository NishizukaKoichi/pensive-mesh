# Execution Plan

Updated: 2026-08-02

## v0.1 contract

Pensive Mesh v0.1 is complete when a person can create and recover an encrypted local vault, import a ChatGPT export repeatedly without duplication, inspect original branches and evidence, review revisable memory claims, search locally, and preview/export a minimal signed Context Pack without enabling a model or any external action path.

## Batches

1. Repository, schemas, threat model, and CI skeleton.
2. Vault encryption, SQLCipher catalog, object store, device identity, signed journal, audit freeze, and recovery.
3. Streaming/safe ChatGPT import, Source/Fragment retrieval, idempotency, quarantine, and injection/secret labels.
4. Memory review, contradiction preservation, lexical retrieval, and Context Pack policy.
5. CLI and Tauri desktop journeys.
6. Unit, integration, negative-security, recovery, packaging, and public CI verification.

## Evidence rule

Every acceptance claim is recorded in `docs/VERIFICATION_REPORT.md` with an automated command, a deterministic fixture, or an explicit external blocker. A roadmap item is not evidence.

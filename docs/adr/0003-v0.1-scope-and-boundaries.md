# ADR 0003: Ship Local Memory Core before claiming v1.0

- Status: accepted
- Date: 2026-08-02

## Decision

Treat v0.1 Local Memory Core as the first public complete scope. Do not claim v1.0 until physical-device, geographic, independent-review, and third-party-reader evidence exists.

The implementation ends at encrypted Context Pack export. It contains no external model, Spell handoff, action executor, or real Arcane transport.

## Why

This is the smallest coherent journey that restores owner control without pretending unverified continuity or action safety. It is locally testable and reversible.

## Alternatives considered

- Scaffold every v1 module: rejected because broad empty interfaces look complete without protecting data.
- Extend the separate `pensieve-local` prototype: rejected because its storage semantics and canonical path are a different variant; silent migration is prohibited.

## Risk and rollback

Public users may expect later roadmap features. README and UI display the version boundary. The encrypted open schemas and append-only event design preserve a migration path; rollback is a verified Backup restored by the previous compatible build.

# Roadmap

## v0.1 — Local Memory Core

Implemented in this repository: encrypted Vault, ChatGPT import, Source/Fragment view, evidence review, local search, signed Context Pack, Recovery Kit, clean local restore, CLI, and macOS Tauri app.

## v0.2 — Contextual Intelligence

Local/opt-in model adapters, hybrid retrieval, versioned Self Map, Ritual Contract review, and model-run audit. No external fallback and no autonomous action.

## v0.3 — Safe Action Bridge

Explicit voice capture, local STT adapter, Intent/Draft, deterministic SimWorld, immutable DRAFT Spell Ticket, signed Receipt import. Separate Spell Kernel still owns identity, Grant, risk, approval, execution, verification, and Undo.

## v0.4 — Arcane Continuity

Ciphertext-only Arcane adapter, incremental object/journal/checkpoint backup, honest replica state, clean restore against real storage domains.

## v0.5 — Multi-device

Signed encrypted sync segment, conflict-safe merge, physical-device revocation, root/key epoch rotation, and a two-physical-device clean test.

## v1.0 — Personal Context Sovereignty

Requires real evidence beyond code: practical use on at least two operating systems, two-device sync, geographic Arcane restore, external security review with high findings resolved, clean Recovery Kit restore, and an independent portable archive reader.

# Code of Conduct

Pensive Mesh contributors must protect the dignity, privacy, and autonomy of people represented in personal context.

We expect respectful collaboration, evidence-backed technical discussion, consent-aware handling of examples, and prompt correction when harm is identified. Harassment, discrimination, threats, doxxing, publication of personal Vault material, or pressure to weaken owner-control boundaries are not acceptable.

Use synthetic fixtures in issues and pull requests. Never post keys, recovery material, real conversations, private identities, health/legal/financial context, or precise locations.

Report conduct concerns privately through the repository owner's GitHub profile or repository Security reporting flow. Maintainers may edit, hide, reject, or remove contributions and participation that violate these rules. Good-faith security research following `SECURITY.md` is welcome.
